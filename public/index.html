SaaS Made Free

Some subscriptions are a business.
Some are just a prompt.

An open directory of the software you pay for every month, and whether a coding agent could rebuild a version you own. One prompt per tool, written to be handed straight to Claude, Cursor or ChatGPT.

Three verdicts

Yes
Replace it today. Nothing important is lost.
Partly
Rebuildable in a weekend, but you give up the mobile app, the sync, the integrations. The entry says which.
No
Keep paying. The value is the network, the data or the compliance — no prompt replaces that.

Four tools published so far. The catalogue is being written, one verified entry at a time.

Where this is

The directory itself is being written. What already exists is public and working: the dataset and its validation, the versioned feed that serves it, the vote backend, and a browser extension that tells you the verdict on the site you are looking at.

All of it is open source, unminified, and the extension is built reproducibly — rebuild it yourself and the archive matches the published hash, byte for byte. That is the only honest answer to an extension that asks to run on every site you visit.
